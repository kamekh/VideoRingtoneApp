# VideoRingtoneApp

Android-приложение для настройки и хранения видео-рингтонов на входящие вызовы.

Что уже есть:
- базовый Android Compose app
- главный экран пользователя
- выбор видео и музыки
- сохранение рингтонов в локальное хранилище
- базовый дизайн Material 3
- безопасный локальный подход без обязательной регистрации

Что будет дальше:
- экран предпросмотра
- редактирование длительности и loop
- установка рингтона на Xiaomi / Poco / Android 10+
- настройка приватного режима
- улучшенный дизайн и UX
- public/social layer после стабилизации v1

Стратегия v1:
- личная библиотека рингтонов
- локальное хранение
- без публичного контента
- без обязательной регистрации
- безопасный и понятный опыт для пользователей

Стратегия v2:
- публикации по явному выбору пользователя
- 18+ ограничения
- moderation / reporting
- trend feed / views / likes
- rewards and achievements

��тратегия v3:
- рейтинг, бонусы, social layer, community features

Запуск:
1. Откройте проект в Android Studio.
2. Дождитесь синхронизации Gradle.
3. Запустите приложение на эмуляторе или устройстве.

Важно:
На Xiaomi и Android 10+ автоматическая установка рингтона может требовать системного диалога или ручного выбора, поэтому приложение должно предлагать безопасный fallback-путь.
